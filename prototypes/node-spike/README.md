# Node/SQLite prototype

Prototype GuBot đầu tiên. Chạy từ repo root bằng `npm run dev:prototype` hoặc `npm run test:prototype`. Khi chạy dev, dữ liệu mặc định lưu tại `prototypes/node-spike/giftu.sqlite`. Có thể dùng `GIFTU_DB` để chỉ đường dẫn database mẫu đã có.

Phiên bản đang phát triển nằm ở [`sites/`](../../sites/), dùng Worker và D1 với một bộ mã catalog/token riêng.
